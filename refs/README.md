# Visual references

Drop screenshots and moodboards here so the agent copies a **real** look instead of inventing stock Roblox UI.

## Folders
| Path | Put here |
|------|----------|
| `refs/ui/` | HUD, menus, buttons, shops from games you want to match (crop to the UI) |
| `refs/mood/` | Color, lighting, atmosphere stills |
| `refs/chars/` | Character / silhouette / animation pose references |
| `refs/avoid/` | Optional: examples of looks we do **not** want |

## Naming
`ui/hud-health-01.png`, `mood/ember-cave-02.png` — short, numbered.

## How agents should use this
1. List files in the relevant folder before designing.
2. Match hierarchy, spacing density, and contrast — don’t literally steal assets.
3. If a folder is empty, follow tokens in `.cursor/skills/roblox-ui-polish` and ask for refs when polish matters.
